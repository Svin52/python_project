# тг бот бля учета посещаемости

Для работы в .env должны быть:
BOT_TOKEN - просто токен
ADMIN_IDS - id админов через запятую
username бота вшит прямо в код в переменную BOT_USERNAME - почему-то у меня все лмоалось, когда я пытался запихать его в .env

### Комманды 

/help - выводит общую информацию про все комманды 

#### Для преподователей

/qr - генерирует qr код, живущий 30 минут, который студентам нужно отсканировать 
/stats - выводит, сколько человек отметились сегодня 

#### Для студентов 

/my  - выводит, вашу посещаемость
/start - без аргументов просто регистрирует вас в системе, если в качестве аргумента передать токен, то отмечает как присутствующего
